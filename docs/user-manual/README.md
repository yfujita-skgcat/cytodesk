# CytoDesk user manual package

- `user_manual.md`: CytoDesk GUI user manual
- `assets/main-window.png`: main-window screenshot referenced by the manual
- `coverage_report.md`: static UI coverage result
- `tools/check_ui_coverage.py`: reproducible static checker

The manual was prepared against the source snapshot in `rep(10).zip` (CytoDesk 0.1.0).
